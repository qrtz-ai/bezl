# Test matrix

This lists every user-facing flow and the tests that cover it. **e2e** means Playwright driving the built Electron app under xvfb (`npm run e2e`); **unit** means vitest (`npm test`); **helper** means Swift tests (`npm run test:helper`); **smoke** means `npm run smoke:packaged`. Update this file when you add a flow.

## Known gaps

- Real macOS capture (ScreenCaptureKit, AX scraping against live Zoom/Meet) needs a Mac with permissions; it is covered by fixtures and the mock helper only.
- The API key happy path (Keychain) only runs on macOS; Linux has no keyring under xvfb.
